# E3 — Odyssey retrieval·legacy baseline

상태: `[ ]` E2 이후 복원  
연결 마일스톤: [M1.5](./M1_5.md)

## 목표

공개 Odyssey의 고정 skill library에서 논문 핵심인 자연어 semantic retrieval와 planner–actor–critic baseline을 복원한다.

## 작업

- [ ] `odyssey-retrieval`, `odyssey-legacy`, `combat` profile 분리
- [ ] 40 primitive + 183 compositional skill과 자연어 description corpus 복원·hash 기록
- [ ] 논문/공개 코드의 Sentence Transformer checkpoint revision 고정
- [ ] 자연어 subgoal query embedding과 top-5 similarity retrieval 재현
- [ ] correct-skill recall@5, candidate coverage, retrieval latency 기록
- [ ] original Chroma 결과를 우선 보존하고 in-memory 대체 구현과 parity 비교
- [ ] fixed candidate와 retrieved candidate에서 actor top-1·online 성공률 비교
- [ ] planner/task decomposition과 critic/reflection/replanning 기능별 ablation
- [ ] MineMA를 포함한 `odyssey-legacy` baseline 고정
- [ ] PVP·Hawkeye는 `combat` profile에서만 복원
- [ ] 원본 JavaScript code/AST 경로와 MineSkynet strict skill-ID 경로 차이 기록
- [ ] E3 동안 skill corpus 쓰기 금지

## 통과 조건

고정 223-skill corpus에서 Sentence Transformer top-5 retrieval와 planner–actor–critic이 재현되고, 각 기능의 기여가 ablation으로 분리돼야 한다. Sentence Transformer나 semantic retrieval을 제거한 결과를 Odyssey 재현으로 보고하지 않는다.
