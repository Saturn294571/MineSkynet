# M3 — Atomic capability calibration

상태: `[ ]` M2 이후 착수

## 목적

scheduler가 사용할 장치·모델별 실제 capability profile을 만든다.

## 작업

- [ ] 공통 atomic task 목록·난이도·초기 world fixture
- [ ] 성공률과 평균·P95 완료 시간
- [ ] peak RAM/VRAM, 에너지와 온도
- [ ] 통신량·retry·timeout
- [ ] 장치·모델·양자화 조합별 반복 측정
- [ ] `P(success)`, latency, energy, retry profile 생성

## 완료 조건

동일 task를 각 노드에서 재현 가능하게 비교하고 allocation에 직접 사용할 수치 profile이 존재해야 한다.
