# M1.75 — Voyager lifelong와 Odyssey Full 확장

상태: `[ ]` E0~E3 안정화 후 병렬 가능한 보존 트랙  
검증 Gate: [E4](./E4.md)

## 목적

Voyager의 능동적 curriculum·code generation/repair·self-verification·skill 축적을 복원하고, 이를 Odyssey의 고정 skill library와 결합한 `odyssey-full`을 별도 확장으로 평가한다.

## 범위

- [ ] `voyager-lifelong` 원형 baseline
- [ ] versioned dynamic skill lifecycle을 결합한 `odyssey-full`
- [ ] sandbox/quarantine과 deterministic+LLM 이중 검증
- [ ] code·description·embedding·provenance 원자적 commit
- [ ] rollback·duplicate·index consistency
- [ ] held-out retrieval·reuse·transfer 평가

## 원칙

E0~E3에서 dynamic skill 쓰기를 비활성화하는 것은 단계적 MVP 격리이며 연구 범위에서 제거하는 것이 아니다. `odyssey-legacy`, `voyager-lifelong`, `odyssey-full`을 서로 다른 결과로 보고한다. 이 마일스톤 완료는 M2 물리 노드 연결의 필수 선행조건은 아니다.

## 완료 조건

[E4](./E4.md)의 전체 lifecycle과 held-out 재사용이 재현되고 static baseline 대비 이득·오염·비용을 함께 측정해야 한다.
