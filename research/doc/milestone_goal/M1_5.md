# M1.5 — 공개 Odyssey baseline 복원

상태: `[ ]` E2 이후 착수  
검증 Gate: [E3](./E3.md)

## 목적

공개 Odyssey의 고정 40 primitive + 183 compositional skill, 자연어 description, Sentence Transformer retrieval, planner–actor–critic과 MineMA를 보존한 비교 baseline을 만든다.

## 범위

- [ ] `odyssey-retrieval`과 `odyssey-legacy` profile
- [ ] skill corpus·description·encoder revision·distance metric·top-k=5 고정
- [ ] recall@5·candidate coverage·actor top-1·online success 측정
- [ ] Chroma legacy 기본값 보존과 대체 vector search parity 비교
- [ ] planner, critic, reflection/replanning의 단계별 ablation
- [ ] combat 기능은 별도 `combat` profile
- [ ] 공개 코드의 비활성 `add_new_skill()` 상태를 기록하고 corpus를 read-only로 유지

## 원칙

Sentence Transformer는 자연어 subgoal과 skill description을 같은 벡터 공간에 놓는 논문 핵심 기능이므로 제거 후보가 아니다. Chroma·LangChain은 구현체로서 비교할 수 있지만 검증된 외부 구현을 우선하고 기능 parity 없이 재작성하지 않는다.

## 완료 조건

[E3](./E3.md)을 통과해 고정-library Odyssey와 MineSkynet 단순화 profile의 차이를 정량적으로 설명할 수 있어야 한다.
