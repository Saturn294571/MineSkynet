# E2 — `e2-actor-fixed` 실제 actor 검증

상태: `[ ]` E1 완료 후 착수  
연결 마일스톤: [M1](./M1.md)

## 목표

고정 candidate 조건에서 실제 actor의 선택 성능을 측정해 retrieval·planner 오류와 모델 자체 오류를 분리한다.

## 작업

- [ ] 짧은 `observation + subgoal + candidate skills → skill_id` 계약 고정
- [ ] 파인튜닝하지 않은 instruct model baseline
- [ ] JSON valid rate, candidate-valid rate, skill top-1 accuracy 측정
- [ ] task별 confusion, latency, peak VRAM·RAM 기록
- [ ] parser와 제한된 재시도 정책 검증
- [ ] base actor의 atomic Minecraft online 성공률 기록
- [ ] 이후에만 과거 Gemma LoRA adapter를 같은 test set에서 비교
- [ ] BF16과 INT4 정확도·지연·메모리 비교
- [ ] MineMA와 Gemma 결과 비교 및 Gemma actor Go/No-Go 판정

## 통과 조건

actor만 교체한 통제 실험에서 offline skill 선택과 online Minecraft 성공을 분리 보고할 수 있어야 한다. 장기 이력, reflection과 동적 skill 생성은 요구하지 않는다.
