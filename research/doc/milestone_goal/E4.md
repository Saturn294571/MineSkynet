# E4 — Voyager lifelong·Odyssey Full

상태: `[ ]` E0~E3 회귀 고정 후 착수  
연결 마일스톤: [M1.75](./M1_75.md)

## 목표

Voyager의 능동 skill 학습과 이를 Odyssey에 결합한 Full 확장을 고정-library Odyssey baseline과 분리해 복원한다.

## 작업

- [ ] `voyager-lifelong`, `odyssey-full` profile·lockfile·model endpoint 계약
- [ ] inventory·성공/실패 이력·skill coverage 기반 automatic curriculum
- [ ] primitive/retrieved skill을 문맥으로 쓰는 JavaScript code generation
- [ ] environment feedback·execution error·critique 기반 제한 횟수 repair
- [ ] deterministic state delta와 LLM self-verification의 이중 검증
- [ ] arbitrary code sandbox와 검증 전 quarantine
- [ ] code·description·embedding·parent·model/prompt·world/commit provenance
- [ ] versioned skill file·registry·vector index의 원자적 commit
- [ ] add/delete/update·중복·색인 불일치·rollback 회귀
- [ ] 새 world와 held-out task에서 retrieval·재사용·전이 평가
- [ ] acceptance/false-accept/repair/duplicate/reuse/cost 지표 기록

## 구현체 원칙

Chroma·LangChain·Sentence Transformer·JavaScript/Babel·model provider adapter는 lifecycle의 서로 다른 역할을 지원한다. 신뢰받는 외부 구현을 기본값으로 보존하며, 대체 구현은 정적 top-5뿐 아니라 add/delete/persist·rollback·재색인 contract parity와 측정 가능한 이득을 보여야 한다.

## 통과 조건

`task 제안 → 검색 → code 생성 → 실행 → 검증 → 수정 → versioned commit·색인 → held-out 재사용` lifecycle이 재현되고, Voyager 원형·공개 Odyssey·`odyssey-full` 결과가 명확히 구분돼야 한다.
