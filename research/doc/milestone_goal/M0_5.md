# M0.5 — 최소 controller와 verifier

상태: `[ ]` M0 완료 후 착수  
검증 Gate: [E1](./E1.md)

## 목적

전체 `Odyssey()` 초기화와 모델 의존성을 우회한 최소 controller를 만들어 endpoint·registry·executor·verifier 계약을 먼저 고정한다.

## 범위

- [ ] fixed observation/subgoal/candidate/request schema
- [ ] 두 atomic skill의 read-only registry
- [ ] deterministic actor stub과 strict output validation
- [ ] inventory/world-state delta verifier
- [ ] 오류 taxonomy와 구조화 trace
- [ ] 두 task 전체 경로 각각 10/10

## 제외 범위

실제 LLM, Sentence Transformer retrieval, planner/critic, dynamic skill 생성·수정은 이 단계에서 초기화하지 않는다. 해당 기능은 제거가 아니라 E2~E4로 연기한다.

## 완료 조건

[E1](./E1.md)을 통과해 모델 품질과 무관하게 controller 계약이 안정적이어야 한다.
