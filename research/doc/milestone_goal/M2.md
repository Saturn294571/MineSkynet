# M2 — 세 물리 노드 연결

상태: `[ ]` M0.5 이후 착수 가능

## 목적

RTX 3090, GTX 1050 Ti와 Raspberry Pi 4B 4GB가 공유 Minecraft 세계에서 각각 독립 bot avatar 하나를 안정적으로 제어하게 한다.

## 작업

- [ ] 세 장비의 OS·CPU·RAM·GPU/VRAM·온도·전력 측정 환경 기록
- [ ] Tailscale/MagicDNS 연결과 시간 동기화
- [ ] 노드별 headless Mineflayer executor 또는 control API
- [ ] agent별 port와 read-only skill registry
- [ ] bot 3개 동시 접속·독립 제어·로그 수집
- [ ] 연결 끊김과 재접속 회귀

Raspberry Pi에서는 Minecraft server가 아니라 headless executor와 허용 가능한 경량 추론만 실행한다.

## 완료 조건

세 물리 장치가 서로의 bot 상태를 덮어쓰지 않고 독립 avatar를 안정적으로 제어해야 한다.
