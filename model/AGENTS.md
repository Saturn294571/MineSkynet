# 모델 어댑터 지침

## 이 디렉터리의 책임

`AbstractLanguageModel` 계약, `init_model.py`의 모델 생성, 공급자별 호출·응답 정규화와 사용량 기록을 맡는다. 공통 규칙은 루트 [AGENTS.md](../AGENTS.md)를 따른다.

## 이 디렉터리만의 규칙

- 공급자별 SDK, 인증, base URL, timeout·retry, 응답 형식은 어댑터 안에 둔다. `pipeline/`이나 `env/`가 특정 공급자 응답 객체를 직접 해석하게 만들지 않는다.
- 출력 텍스트뿐 아니라 실제 호출 수, token, 비용 추정 근거와 `finish_reason`을 분리해 기록한다. 응답 절단·파싱 실패·네트워크 오류를 정상적인 빈 응답으로 숨기지 않는다.
- API 키나 키가 포함된 설정 dict를 출력·로그·예외 메시지에 남기지 않는다. 인증 정보는 환경 또는 명시된 비공개 입력에서만 받고 저장소 파일에 복사하지 않는다.
- 새 모델을 연결할 때는 공통 인터페이스를 통과하는 오프라인 대역 응답과 오류 경로를 먼저 검증한다. 외부 호출 테스트는 요청 범위·예상 비용을 확인하고 최소 횟수로 수행한다.
- 모델·가격·token 집계 조건 변경은 이전 실험과의 비교에 영향을 주므로 revision과 적용 시점을 명시한다.
